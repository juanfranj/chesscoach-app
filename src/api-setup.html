Setup Guide

AI Coach Configuration

Connect Chess Coach to an AI provider to unlock intelligent chess coaching. Choose one provider and follow its setup guide.

What are API keys?

An API key is a unique password that lets Chess Coach connect to an AI service to analyze your chess games. Think of it like a library card — it identifies you so the AI provider knows who is making the request.

You only need to set up ONE provider. Choose whichever suits you best. Your key is stored encrypted on your device and never shared.

💡 Not sure which to pick? Go with OpenAI if you already have a ChatGPT account — it is the cheapest of the lot for this kind of use, and the one that makes the fewest mistakes in our tests. Or go with DeepSeek, almost as cheap. If you would rather not add a card at all, Gemini is the only one with a real free tier.
