Step-by-step guide

1
Create an account

Visit console.anthropic.com and click "Sign up".

2
Verify your email (Magic Link)

Anthropic uses magic links instead of passwords. Check your email and click the verification link. You'll use this method every time you log in.

3
Complete onboarding

Enter your full name, confirm you're over 18, and accept the terms of service.

4
Create your organization

Enter an organization name (can be your personal name).

5
Get free credits (optional)

Try verifying your phone number to get $5 in free credits. This works in many countries but not all. If it doesn't work in your region, you'll need to add a payment method.

6
Set up billing (if needed)

If free credits aren't available, go to Settings → Billing → Add credits. Anthropic uses a prepaid system — you buy credits upfront (minimum $5).

7
Navigate to API Keys

Go to Settings → API Keys or visit console.anthropic.com/settings/keys.

8
Create an API key

Click "+ Create Key", give it a name like "Chess Coach".

9
Copy your key immediately!
⚠️ IMPORTANT: The key (starts with sk-ant-...) is only shown ONCE. Copy it immediately!
10
Paste in Chess Coach

Open Chess Coach → Settings → AI section → Select "Claude Haiku 4.5" → Configure → Paste your API key.
