OpenAI API Key Setup

Follow these steps to get your OpenAI API key and start using GPT-5.6 Luna in Chess Coach for intelligent chess coaching.

Great quality, affordable pricing
📱
Phone Verification

Credit Card
Needed for API usage

Step-by-step guide

1
Create an account

Visit platform.openai.com and click "Sign up". You can use email, Google, Microsoft, or Apple.

2
Verify your email

Check your inbox and click the verification link sent by OpenAI.

3
Verify your phone number

OpenAI requires SMS verification. Enter your phone number and the code you receive via text message.

4
Set up billing

Go to Settings → Billing → Add payment method. You need to add credits (minimum ~$5) to use the API.

💡 You can skip this initially, but the API won't work without credits loaded into your account.
5
Navigate to API Keys

In the left sidebar, click "API Keys" or go directly to platform.openai.com/api-keys.

6
Create a new secret key

Click "Create new secret key". Give it a descriptive name like "Chess Coach".

7
Copy your key immediately!

Your API key (starts with sk-...) is displayed. Copy it right away.

⚠️ IMPORTANT: The key is only shown ONCE. If you close the dialog without copying it, you'll need to create a new one. There is no way to view it again.
8
Paste in Chess Coach

Open Chess Coach → Settings → AI section → Select "OpenAI GPT-5.6 Luna" → Configure → Paste your API key.

✅ Your key is stored securely on your device using AES-256-GCM encryption. It is never sent to our servers.

Important notes

💰 Set a spending limit in Settings → Billing → Usage limits to avoid unexpected charges. We recommend starting with $5-10/month.
🔓 The API key is separate from a ChatGPT Plus subscription. Having ChatGPT Plus does not give you API access; you need to add credits separately.
📈 Rate limits increase as you spend more (Tier system). New accounts start at Tier 1. For Chess Coach usage, Tier 1 is more than sufficient.
