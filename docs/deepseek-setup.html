DeepSeek API Key Setup

Complete guide to creating your API key and adding funds for the most affordable AI provider.

Part 1

Creating your API Key

1
Create an account

Visit platform.deepseek.com and click "Sign Up".

2
Verify your email

Check your inbox and click the verification link.

3
Phone verification (optional)

Phone verification is optional but recommended. Supports international numbers from 180+ countries.

4
Navigate to API Keys

In the left sidebar, click "API Keys".

5
Create API Key

Click "Create API Key" and give it a descriptive name (e.g. "Chess Coach").

6
Copy your key

Copy the key immediately — it won't be shown again after closing the window.

7
Paste in Chess Coach

Open Chess Coach → Settings → AI section → Select "DeepSeek Chat" → Configure → Paste your API key.

Part 2

Adding Funds (for international users)

⚠️
Payment may be challenging

DeepSeek is a Chinese company and payment can be challenging for users outside China. Below are your options, from easiest to most involved.

A
Use your free tokens first
Recommended
New accounts get 5 million free tokens. This is enough for many analysis sessions. Try it before worrying about payment.
B
PayPal
If PayPal is available in your country:
  1. Go to platform.deepseek.com/top_up
  2. Select "PayPal"
  3. Follow the PayPal payment flow
  4. Minimum top-up: ~$2
Note: PayPal is NOT available in all countries. If you see an error, try the other options.
C
Bank Card
  1. Go to Top Up → Select "Bank Card"
  2. Enter your Visa/Mastercard details
  3. Some international cards may be rejected depending on your region
D
Virtual Card with Crypto
If PayPal and bank cards don't work, you can use a crypto-funded virtual card:
  1. Create an account on a service like Kazawallet (kazawallet.com) — requires identity verification (KYC)
  2. Deposit cryptocurrency (USDT recommended for stability)
  3. Convert to USD and issue a virtual Visa card
  4. Use the virtual card details in DeepSeek's "Bank Card" payment option
Note: fees apply (~4% total).
E
Use OpenRouter as intermediary
Recommended alternative
If you can't pay DeepSeek directly, OpenRouter.ai acts as a middleman:
  1. Create an account at openrouter.ai
  2. Buy credits with a normal credit card (they use Stripe — works worldwide)
  3. In Chess Coach settings, use the OpenRouter API key instead
💡 Chess Coach's DeepSeek provider uses the same API format as OpenRouter, making this a seamless alternative.
