Configurar API Key de DeepSeek

Guía completa para crear tu API key y agregar fondos en el proveedor de IA más económico.

$ Muy económico para análisis de ajedrez ($0.22/M entrada, $0.66/M salida)
💰 5 millones de tokens gratis al registrarte (sin tarjeta de crédito)
🔗 API compatible con el formato de OpenAI
Parte 1

Crear tu API Key

1
Crear una cuenta

Visita platform.deepseek.com y haz clic en "Sign Up".

2
Verificar tu email

Revisa tu bandeja de entrada y haz clic en el enlace de verificación.

3
Verificación telefónica (opcional)

La verificación telefónica es opcional pero recomendada. Admite numeros internacionales de más de 180 países.

4
Ir a API Keys

En la barra lateral izquierda, haz clic en "API Keys".

5
Crear API Key

Haz clic en "Create API Key" y ponle un nombre descriptivo (ej. "Chess Coach").

6
Copiar tu clave

Copia la clave inmediatamente — no se mostrará de nuevo después de cerrar la ventana.

7
Pegar en Chess Coach

Abre Chess Coach → Ajustes → Sección IA → Selecciona "DeepSeek Chat" → Configurar → Pega tu API key.

Parte 2

Agregar Fondos (para usuarios internacionales)

⚠️
El pago puede ser complicado

DeepSeek es una empresa china y el pago puede ser complicado para usuarios fuera de China. A continuación tus opciones, de la más fácil a la más compleja.

A
Usa tus tokens gratis primero
Recomendado
Las cuentas nuevas reciben 5 millones de tokens gratis. Esto es suficiente para muchas sesiones de análisis. Pruebalo antes de preocuparte por el pago.
B
PayPal
Si PayPal está disponible en tu país:
  1. Ve a platform.deepseek.com/top_up
  2. Selecciona "PayPal"
  3. Sigue el flujo de pago de PayPal
  4. Recarga minima: ~$2
Nota: PayPal NO está disponible en todos los países. Si ves un error, prueba las otras opciones.
C
Tarjeta Bancaria
  1. Ve a Top Up → Selecciona "Bank Card"
  2. Introduce los datos de tu Visa/Mastercard
  3. Algunas tarjetas internacionales pueden ser rechazadas dependiendo de tu región
D
Tarjeta Virtual con Cripto
Si PayPal y las tarjetas bancarias no funcionan, puedes usar una tarjeta virtual financiada con cripto:
  1. Crea una cuenta en un servicio como Kazawallet (kazawallet.com) — requiere verificación de identidad (KYC)
  2. Deposita criptomonedas (USDT recomendado por estabilidad)
  3. Convierte a USD y emite una tarjeta Visa virtual
  4. Usa los datos de la tarjeta virtual en la opción "Bank Card" de DeepSeek
Nota: se aplican comisiones (~4% en total).
E
Usar OpenRouter como intermediario
Alternativa recomendada
Si no puedes pagar a DeepSeek directamente, OpenRouter.ai actua como intermediario:
  1. Crea una cuenta en openrouter.ai
  2. Compra créditos con una tarjeta de crédito normal (usan Stripe — funciona en todo el mundo)
  3. En los ajustes de Chess Coach, usa la API key de OpenRouter en su lugar
💡 El proveedor DeepSeek de Chess Coach usa el mismo formato de API que OpenRouter, lo que hace que sea una alternativa transparente.
