Guía paso a paso

1
Ve a Google AI Studio

Visita aistudio.google.com y haz clic en "Get Started".

2
Inicia sesión con Google

Usa cualquier cuenta de Google (Gmail). Si no tienes una, créala en accounts.google.com.

3
Acepta los Términos de Servicio

Lee y acepta los Términos de Servicio de Google AI Studio para continuar.

4
Navega a API Keys

En la barra lateral izquierda, haz clic en "API Keys", o ve directamente a aistudio.google.com/app/apikey.

5
Crea la API Key

Haz clic en "Create API Key". Selecciona un proyecto de Google Cloud (se creara uno automáticamente si no tienes ninguno).

6
Copia tu clave

Copia la API key generada (empieza con AIza...). Guardala en un lugar seguro — siempre puedes generar una nueva si la pierdes.

📋 Consejo: Haz clic en el icono de copiar junto a la clave para copiarla al portapapeles al instante.
7
Pega en Chess Coach

Abre Chess Coach → Ajustes → Sección IA → Selecciona "Gemini" → Configurar → Pega tu API key.

Precios

🇪🇺 UE / EEE / Reino Unido / Suiza: Google requiere una cuenta de facturación por el RGPD. Una vez vinculada, todo el uso es de pago — pero para coaching de ajedrez normal el coste es de solo unos céntimos al mes.

🌐 Fuera de la UE/EEE: Gemini ofrece un plan gratuito (250 req/día para Flash Lite, 100 para Flash) que no requiere cuenta de facturación. Si estás fuera de Europa, puedes usar Gemini sin coste.

Usuarios de la UE / EEE: Cuenta de facturación necesaria

⚠️ Si estás en la Unión Europea, EEE, Reino Unido o Suiza, Google requiere una cuenta de facturación para usar la API de Gemini. Es una restricción del RGPD. Una vez vinculada, todo el uso de la API es de pago (el plan gratuito no aplica). Sin embargo, el coste para coaching de ajedrez normal es de solo unos céntimos al mes.
1
Ve a Google Cloud Billing

Visita console.cloud.google.com/billing e inicia sesión con la misma cuenta de Google que usaste para tu API key.

2
Crea una cuenta de facturación

Haz clic en "Crear cuenta" o "Vincular una cuenta de facturación". Introduce tus datos de pago (tarjeta de crédito/débito). Todo el uso se facturara, pero el coaching de ajedrez suele costar menos de 0,15€/mes.

3
Vincula a tu proyecto

Asegurate de que la cuenta de facturación está vinculada al proyecto de Google Cloud que contiene tu API key. Puedes comprobarlo en Facturación → Mis proyectos.

4
Configura una alerta de presupuesto (recomendado)

Ve a Facturación → Presupuestos y alertas → "Crear presupuesto". Establece el importe en 1€ con alertas al 50%, 90% y 100%. Así recibirás un email si se produce algún cargo inesperado.

Consejos

⏳ Si alcanzas el límite de solicitudes (error 429), espera un minuto e intentalo de nuevo. El límite se restablece diariamente.
🇪🇺 Usuarios UE/EEE: Con cuenta de facturación obtienes límites más altos (2.000 RPM vs 10 RPM) y tus datos no se usan para entrenar modelos (compatible con RGPD).
🌐 Usuarios fuera de la UE: El plan gratuito (sin facturación) es permanente y no caduca.
⭐ Gemini Flash Lite es una opción muy asequible para coaching de ajedrez. Incluso con facturación, un mes típico cuesta menos que un cafe.
