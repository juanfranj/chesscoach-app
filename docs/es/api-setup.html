Coach IA Configuración

Conecta Chess Coach a un proveedor de IA para desbloquear el coaching inteligente de ajedrez. Elige un proveedor y sigue su guía de configuración.

¿Qué son las API keys?

Una API key es una contraseña única que permite a Chess Coach conectarse a un servicio de IA para analizar tus partidas de ajedrez. Piensa en ella como una tarjeta de biblioteca — te identifica para que el proveedor de IA sepa quién hace la solicitud.

Solo necesitas configurar UN proveedor. Elige el que mejor se adapte a ti. Tu clave se almacena cifrada en tu dispositivo y nunca se comparte.

💡 ¿No sabes cuál elegir? Ve con OpenAI si ya tienes cuenta de ChatGPT: es el más barato para este uso y el que menos se equivoca en nuestras pruebas. O con DeepSeek, casi igual de barato. Y si prefieres no poner tarjeta, Gemini es el único con plan gratuito de verdad.
