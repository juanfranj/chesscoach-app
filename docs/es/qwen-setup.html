Configurar API Key de Qwen

Guía completa para crear tu API key en Alibaba Cloud Model Studio, el proveedor más barato de Chess Coach.

Parte 1

Crear tu API Key

1
Crear una cuenta de Alibaba Cloud

Visita Alibaba Cloud Model Studio y registrate con tu email. Model Studio es la consola que sirve los modelos Qwen.

2
Elegir la región de Singapur

La primera vez que entras, la consola te pide elegir una región. Quedate en Singapur (ap-southeast-1): es el endpoint internacional con el que habla Chess Coach. Una clave creada en otra región no funcionara.

3
Si la consola sale en chino

Pasa, y desconcierta la primera vez. Usa el selector de idioma de la parte superior de la página para cambiar a inglés. El botón que buscas pone "Create API Key" en inglés y "创建 API Key" en chino.

4
Abrir la página de API Keys

Ve a la sección API Key de la consola (barra lateral izquierda, "API Key").

5
Crear API Key

Haz clic en "Create API Key". Deja el workspace por defecto, escribe la descripción que quieras (ej. "Chess Coach") y deja los permisos en "All".

6
Copia la clave AHORA

La clave se muestra una sola vez. Cópiala o descargala en ese mismo momento, antes de cerrar el diálogo. Si la pierdes no hay forma de volver a verla — solo puedes borrarla y crear otra.

7
Pegar en Chess Coach

Abre Chess Coach → Ajustes → Sección IA → Selecciona "Qwen 3.7 Flash" → Configurar → Pega tu API key.

⚠️
La clave solo se muestra una vez

Este es el paso que más problemas da. Alibaba Cloud no te deja volver a mirar una clave ya creada: cópiala o descargala en el momento en que aparece en pantalla.

Parte 2

Elegir tu modelo

A
Qwen 3.7 Flash
Recomendado
El modelo más barato de toda la app: $0.03 por millon de tokens de entrada y $0.13 por millon de tokens de salida. Responde rápido y va sobrado para el coaching jugada a jugada.
Chess Coach desactiva el modo de razonamiento de Qwen en este modelo, para que cada análisis sea tan pequeño (y tan barato) como parece.
B
Qwen 3.7 Plus
El nivel potente: $0.32 por millon de tokens de entrada y $1.28 por millon de tokens de salida. Piensa antes de responder, así que las explicaciones son más profundas — y cada análisis cuesta bastante más que con Flash.
Los dos modelos usan la misma API key. Puedes cambiar de uno a otro en los ajustes de Chess Coach cuando quieras.
