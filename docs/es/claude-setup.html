Guía paso a paso

1
Crea una cuenta

Visita console.anthropic.com y hace clic en "Sign up".

2
Verifica tu email (Magic Link)

Anthropic usa magic links en vez de contraseñas. Revisa tu email y hace clic en el enlace de verificación. Usarás este método cada vez que inicies sesión.

3
Completa el registro

Ingresa tu nombre completo, confirma que sos mayor de 18 y acepta los términos de servicio.

4
Crea tu organización

Ingresa un nombre de organización (puede ser tu nombre personal).

5
Obtene créditos gratuitos (opcional)

Intenta verificar tu número de teléfono para obtener $5 en créditos gratuitos. Esto funciona en muchos países pero no en todos. Si no funciona en tu región, necesitarás agregar un método de pago.

6
Configura la facturación (si es necesario)

Si los créditos gratuitos no están disponibles, ve a Settings → Billing → Add credits. Anthropic usa un sistema prepago — compras créditos por adelantado (mínimo $5).

7
Navega a API Keys

Ve a Settings → API Keys o visita console.anthropic.com/settings/keys.

8
Crea una API key

Hace clic en "+ Create Key", dale un nombre como "Chess Coach".

9
Copia tu key inmediatamente!
⚠️ IMPORTANTE: La key (empieza con sk-ant-...) solo se muestra UNA VEZ. Cópiala inmediatamente!
10
Pega en Chess Coach

Abri Chess Coach → Settings → Sección IA → Selecciona "Claude Haiku 4.5" → Configurar → Pega tu API key.
