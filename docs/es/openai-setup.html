Configuración de API Key de OpenAI

Sigue estos pasos para obtener tu API key de OpenAI y comenzar a usar GPT-6 Luna en Chess Coach para coaching inteligente de ajedrez.

Lo que obtendrás

🤖
GPT-6 Luna
Gran calidad, precio accesible
📱
Verificación telefónica
Verificación por SMS requerida
💳
Tarjeta de crédito
Necesaria para uso de la API

Guía paso a paso

1
Crea una cuenta

Visita platform.openai.com y haz clic en "Sign up". Puedes usar email, Google, Microsoft o Apple.

2
Verifica tu email

Revisa tu bandeja de entrada y haz clic en el enlace de verificación enviado por OpenAI.

3
Verifica tu número de teléfono

OpenAI requiere verificación por SMS. Introduce tu número de teléfono y el código que recibas por mensaje de texto.

4
Configura la facturación

Ve a Settings → Billing → Add payment method. Necesitas agregar créditos (mínimo ~$5) para usar la API.

💡 Puedes omitir esto inicialmente, pero la API no funcionara sin créditos cargados en tu cuenta.
5
Navega a API Keys

En la barra lateral izquierda, haz clic en "API Keys" o ve directamente a platform.openai.com/api-keys.

6
Crea una nueva clave secreta

Haz clic en "Create new secret key". Dale un nombre descriptivo como "Chess Coach".

7
Copia tu clave inmediatamente!

Tu API key (comienza con sk-...) se muestra en pantalla. Cópiala de inmediato.

⚠️ IMPORTANTE: La clave solo se muestra UNA VEZ. Si cierras el diálogo sin copiarla, tendrás que crear una nueva. No hay forma de verla de nuevo.
8
Pega la clave en Chess Coach

Abre Chess Coach → Ajustes → Sección IA → Selecciona "OpenAI GPT-6 Luna" → Configurar → Pega tu API key.

✅ Tu clave se almacena de forma segura en tu dispositivo usando cifrado AES-256-GCM. Nunca se envía a nuestros servidores.

Notas importantes

💰 Configura un límite de gasto en Settings → Billing → Usage limits para evitar cargos inesperados. Recomendamos empezar con $5-10/mes.
🔓 La API key es independiente de una suscripción a ChatGPT Plus. Tener ChatGPT Plus no te da acceso a la API; necesitas agregar créditos por separado.
📈 Los límites de uso aumentan a medida que gastas más (sistema de Tiers). Las cuentas nuevas comienzan en Tier 1. Para el uso de Chess Coach, el Tier 1 es más que suficiente.
